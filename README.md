# 🥗 NutriTrack — Smart Nutrition & Grocery Planner

NutriTrack is a full-stack nutrition and grocery planning application that helps users set personalized nutrition goals, discover suitable food products, plan meals, and build healthier grocery baskets.

## ✨ Key Features

- User registration and login
- Personalized nutrition goal setting
- Daily calorie and protein target estimation
- Manual food search and filtering
- Automatic food recommendations based on saved goals and dietary preferences
- Meal planning and grocery basket management
- Quantity-aware basket calculations
- Basket health score and nutrition insights
- Responsive web application and mobile application support

## 🛠️ Technology Stack

**Frontend:** React, TypeScript, Vite, CSS

**Backend:** Node.js, Express.js, TypeScript

**Database:** PostgreSQL

**Mobile:** React Native, Expo

**Other:** REST APIs, nutrition data processing, data structures and algorithms

## 📁 Project Structure

- `website/` — React web application
- `backend/` — Express and TypeScript API
- `mobile/` — Mobile application
- `database/` — Database-related files
- `data/` — Nutrition datasets
- `docs/` — Project documentation
- `legacy/` — Earlier project implementation

## 🚀 Project Goal

To make nutrition-aware grocery planning easier by connecting personal dietary goals with food selection, meal planning, and grocery basket management.
