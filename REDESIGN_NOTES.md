# NutriTrack visual refresh

This update refreshes both the React/Vite website and the Expo/React Native app with a premium forest-green, emerald, sage and warm-cream visual system.

## Updated areas
- Website: shared colors, navigation, dashboard hero, buttons, forms, product cards, responsive mobile navigation and cards.
- Mobile: matching palette, elevated auth card, refined dashboard hero and basket/catalogue cards.
- Product presentation: catalogue and basket artwork now varies by food name using category-appropriate emoji illustrations. No fabricated product photography or nutrition data was added.

## Apply
Replace your existing NutriTrack project files with this updated project folder. Your local `backend/.env` is intentionally excluded from this ZIP; keep your existing file and do not overwrite it.

## Run
Backend: `cd backend; npm run dev`
Website: `cd website; npm run dev`
Mobile: `cd mobile; npm install; npx expo start --lan`
