# Data import templates

`ifct2017_foods.csv` is a reviewed-transcription template only. IFCT's publication restricts electronic storage/reproduction for creating a product without prior written permission from ICMR-NIN. Do not populate/import this data into NutriTrack until written permission is obtained. The importer includes a guard for this reason.

The initial live data acquisition is through the USDA FoodData Central API importer in `backend/src/services/importFoodDataCentral.ts`.
